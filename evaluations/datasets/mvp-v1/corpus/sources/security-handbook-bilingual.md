# Security Help / 安全支持

## Incident reporting

Employees should report a suspected security incident through the internal incident portal. The synthetic training contact printed in this sample is helpdesk@example.invalid; it is reserved for evaluation and does not reach a real person.

## 安全事件报告

发现疑似安全事件后，员工应使用内部事件门户提交报告。不得在公共聊天频道中粘贴访问令牌、密码或客户数据。
